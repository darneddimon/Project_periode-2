Ik leer webontwikkeling en maak mijn eerste digitale project

Hoi! Mijn naam is Dima Porkhun. Dit is mijn studeportfolio, dat ik helemaal vanaf nul opmaak als onderdeel van een schoolproject. Al bijna een maand duik ik in de wereld van frontend-ontwikkeling: ik leer hoe een webpagina in elkaar zit, maak me HTML en CSS eigen, experimenteer met stijlen en maak gebruiksvriendelijke navigatie. Deze site is niet zomaar een eindproject, maar een visueel verslag van mijn leerproces, waarin elk element met de hand is geschreven.

Over het project en de specialiteit

Ik studeer voor Software Developer, en dit portfolio is mijn schoolproject. Hier documenteer ik mijn weg in softwareontwikkeling: van het begrijpen van basisalgoritmes en werken met code tot het maken van gebruiksvriendelijke interfaces.

Navigatie en secties

Alle informatie over mijn projecten, taken en leerproces is verdeeld over 4 extra pagina's. Gebruik het vaste bovenmenu om tussen de secties te schakelen en mijn werk te bekijken.

Technologische stack en vooruitgang

In drie weken heb ik de basislogica van programmeren geleerd, werken met layout (HTML/CSS) voor het maken van UI, en ook de projectstructuur. Ik leer hoe ik schone, leesbare code kan schrijven en begrijpen hoe software van binnen wert.
